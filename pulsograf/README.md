# Пульсограф

Прототип: пульс, вариабельность сердечного ритма (HRV) и частота дыхания по камере телефона, без дополнительных устройств.

**Открыть:** https://iliafreedive-del.github.io/factory/pulsograf/

## Как это работает

1. Палец закрывает основную камеру и вспышку. Фонарик подсвечивает кожу, и с каждым ударом сердца её цвет чуть меняется (фотоплетизмография, PPG).
2. Страница берёт средний цвет центра кадра, фильтрует сигнал (0,5–4 Гц) и находит каждый удар сопоставлением с усреднённой формой пульсовой волны.
3. Интервалы между ударами чистятся от помех. По ним считаются пульс, RMSSD, SDNN, pNN50, а частота дыхания берётся из дыхательной волны в ритме сердца.
4. Самооценка по шкале Хокинса сохраняется рядом с замером как субъективная отметка, телефон её не измеряет.

Всё считается в браузере, данные остаются на устройстве (localStorage).

Это не медицинский прибор.
