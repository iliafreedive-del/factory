# Завод прицепов

Браузерная изометрическая игра-визуализация завода: цеха, склады, площадки, маршрут рамы от резки до отгрузки. Приблизьте цех, и крыша пропадёт.

Открыть: https://iliafreedive-del.github.io/factory/

Вся игра в одном файле `index.html` (Three.js r128 с CDN).

## Ссылки

- `#top` — вид сверху, как на 2ГИС.
- `#IMG_1524`, `#V1890_0014` — вид с земли с точки, где снят кадр (по имени кадра, номер не сдвигается).
- `#photo77` — то же по номеру точки (номера 0–88 как до 29.10, новые точки 29.10 — 89–95).
- `#v=10.0,40.0,0.62,0.700,2.50` — ракурс: x и z в метрах плана, поворот, наклон, масштаб. Кнопка «Ссылка на вид» копирует такой адрес.
- `#paint`, `#asm2`… — участок по id из карточек.

## Панель «Поиск» (лупа или клавиша /)

Поиск по зданиям, участкам, вопросам и кадрам; «Новое» — что изменилось; «Вопросы» — все вопросы к заводу списком; «Метки» — замечания на карте (хранятся в браузере, «Скопировать все» отдаёт их текстом); линейка по плану, точки фото, снимок экрана.

Сборка: `python3 tools/plan_from_2gis.py > plan/plan.json && python3 tools/build.py` (вставляет план в `index.html`).
